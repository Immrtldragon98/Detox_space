# Detox Space Beta Test

## Install

1. Download the APK from the latest GitHub prerelease.
2. Allow installation from your browser or file manager when Android asks.
3. Install Detox Space and allow notifications.

This beta APK is not Play Store signed. A later APK built with a different test key may require uninstalling the earlier beta first.

## Two-phone test

1. Install the same APK on two Android phones using different networks.
2. Create a different account on each phone.
3. On phone A, create a private connection code.
4. Enter that code on phone B and confirm both users appear as trusted people.
5. Send `Walk?`, `Coffee?`, `Talk?`, and `Free?` invitations in both directions.
6. Test `I'm in`, `Later`, `Not today`, cancellation, and completion.
7. Close the receiving app completely and verify a generic notification arrives.
8. Turn one phone offline, send/retry an invitation, reconnect, and confirm synchronization.
9. Sign into one account on a second device, then revoke it from Settings.
10. Test removing and blocking a connection.
11. Create a disposable account and verify permanent account deletion signs it out.

## Report a problem

Include the phone model, Android version, account username (never the password), exact steps, expected result, actual result, and a screenshot if it contains no private note or email address.
